# TimeOut logo

The mark is a referee's **T** (the "timeout" hand signal), slanted 10° to match the italic Barlow Condensed wordmark.

## `primary/`: the app logo

This is the version used in the iOS app and the web demo.

| File | Use |
| --- | --- |
| `timeout-icon.svg`, `timeout-icon-rounded-1024.png` | App icon with rounded corners (docs, slides, social) |
| `timeout-icon-ios.svg`, `timeout-icon-1024.png` | Full-bleed square, no transparency. iOS rounds the corners itself. Same file as `AppIcon` in Xcode |
| `timeout-mark.svg` | The T by itself in green, for dark backgrounds |
| `timeout-mark-ink.svg` | The T by itself in near-black, for green or light backgrounds |
| `timeout-lockup-on-dark.png` | Icon + TIMEOUT wordmark, transparent, white text |
| `timeout-lockup-on-light.png` | Icon + TIMEOUT wordmark, transparent, dark text |

## `alternate-meter/`: alternate logo (not used in the app)

The same T, but the crossbar is a screen-time bar that's two-thirds full, on a near-black tile.
It's kept here as an option and isn't wired into the iOS app or the web demo.
